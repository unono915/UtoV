# UtoV

유튜브 영상에서 **원하는 구간만 골라 내려받는** 윈도우 데스크톱 프로그램입니다.
수업 자료로 쓸 3분짜리 장면 하나를 위해 40분짜리 영상을 통째로 받을 필요가 없습니다.

<img src="assets/icon.png" width="72" alt="UtoV 아이콘" />

**[내려받기 및 소개 페이지 →](https://unono915.github.io/UtoV/)**

## 무엇을 할 수 있나

- 유튜브 주소를 붙여 넣으면 제목, 길이, 화질, 챕터를 읽어 옵니다.
- 창 안의 미리보기로 영상을 보면서 **시작과 끝 지점을 집어** 그 구간만 받습니다.
- 지정한 구간만 내려받으므로 전체를 받는 것보다 훨씬 빠르고 용량도 적게 씁니다.
- MP4(영상) 또는 MP3(소리)로 저장하고, 자막을 따로 받거나 영상에 넣을 수 있습니다.
- 여러 개를 줄 세워 받을 수 있고, 진행률과 남은 시간이 보입니다.

## 왜 웹이 아니라 데스크톱 앱인가

| | 웹 서비스 | 데스크톱 앱 |
|---|---|---|
| 유튜브 봇 차단 | 클라우드 IP가 자주 막힘 | 쓰는 사람의 실제 IP라 안정적 |
| 트래픽 | 서버가 받아서 다시 보냄(2배) | PC로 바로 저장 |
| 속도 | 서버 대역폭에 종속 | 인터넷 속도 그대로 |
| 저장 위치 | 브라우저 다운로드 폴더 | 원하는 폴더 |

배포가 번거롭다는 웹의 유일한 장점은 무설치 실행 파일 하나를 공유하는 것으로 해결됩니다.

## 쓰는 법

### 이미 만들어진 파일로 쓸 때

1. `UtoV-1.0.0-무설치.exe` 를 받아서 원하는 곳에 둡니다.
2. 두 번 눌러 실행합니다. 윈도우가 "PC를 보호했습니다" 라고 하면
   **추가 정보 → 실행** 을 누릅니다. (서명되지 않은 프로그램이라 나오는 안내입니다.)
3. 첫 실행 때 `yt-dlp` 와 `ffmpeg` 를 자동으로 내려받습니다. 한 번만 하면 됩니다.

### 소스에서 실행할 때

```bash
npm install
npm start
```

도구를 미리 받아 두려면 (선택):

```bash
npm run setup
```

### 배포 파일 만들기

```bash
npm run dist
```

`release/` 에 두 가지가 생깁니다.

| 파일 | 쓰임 |
|---|---|
| `UtoV-1.0.0-portable.exe` | 무설치. 복사해서 두 번 누르면 실행됩니다. 나눠 쓰기 편합니다. |
| `UtoV-1.0.0-setup.exe` | 설치본. 시작 메뉴와 바탕화면 바로가기를 만듭니다. |

yt-dlp 와 ffmpeg 는 배포 파일에 넣지 않습니다. 합쳐서 300MB 가 넘고,
yt-dlp 는 유튜브 변경에 맞춰 자주 갱신해야 하기 때문입니다.
대신 앱이 첫 실행 때 내려받아 `%APPDATA%\UtoV\bin` 에 둡니다.

**학교망에서 GitHub 가 막혀 있다면** 다른 PC 에서 `npm run setup` 으로 받은
`bin/` 안의 `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` 세 파일을
그 PC 의 `%APPDATA%\UtoV\bin` 에 직접 넣어 주면 됩니다.

## 구조

```
src/
  main/            일렉트론 메인 프로세스
    main.js        창, IPC
    ytdlp.js       yt-dlp 실행기 (정보 조회, 구간 다운로드)
    tools.js       yt-dlp / ffmpeg 자동 준비와 갱신
    server.js      화면을 127.0.0.1 로 서빙 (유튜브 미리보기용)
    paths.js       도구 경로 찾기
    store.js       설정 저장
    preload.js     화면에 열어 주는 창구
  renderer/        화면 (HTML / CSS / JS)
scripts/
  fetch-binaries.mjs  도구 미리 받기
  make-icon.py        아이콘 생성
```

구간 다운로드는 yt-dlp 의 `--download-sections` 에 `--force-keyframes-at-cuts` 를 붙여
필요한 부분만 받은 뒤 지정한 시각에 정확히 맞춰 잘라내는 방식입니다.

## 잘 안 될 때

**"사람인지 확인하세요" 또는 연령 제한 오류**
설정(톱니바퀴) → 브라우저 쿠키를 Chrome 이나 Edge 로 바꾸고 다시 시도하세요.
쿠키를 읽는 동안에는 그 브라우저를 닫아 두어야 합니다.

**갑자기 아무 영상도 안 받아질 때**
유튜브가 내부 구조를 바꾼 경우입니다. 설정 → **yt-dlp 갱신** 을 누르면 대개 해결됩니다.

**"요청 속도를 제한했습니다" (HTTP 429)**
목록의 **천천히 다시** 를 누르면 조각을 한 번에 하나씩, 요청 사이를 띄워 가며 다시 받습니다.
자주 겪는다면 설정 → 브라우저 쿠키를 지정하세요. 로그인된 요청으로 취급되어 제한을 훨씬 덜 받습니다.
여러 사람이 한 회선을 나눠 쓰는 학교망에서는 같은 공인 IP 로 묶여 더 자주 발생합니다.

**학교망에서 느리거나 끊길 때**
설정 → 동시 조각 수를 1 또는 3 으로 낮춰 보세요.

## 알아 둘 점

- 화면을 `127.0.0.1` 의 임의 포트로 띄웁니다. 유튜브 미리보기 iframe 이
  `file://` 출처에서는 막히기 때문이며, 루프백 주소에만 연결하고 임의 토큰 경로 아래에서만
  파일을 내줍니다.
- `bin/` 폴더의 yt-dlp 와 ffmpeg 는 저장소에 포함하지 않습니다(300MB 이상).
  앱이 필요할 때 내려받아 `%APPDATA%\UtoV\bin` 에 둡니다.
- 이 저장소를 OneDrive 안에 두면 `node_modules` 와 `bin` 이 함께 동기화되어 느려집니다.
  해당 폴더는 동기화에서 빼 두는 편이 좋습니다.

## 저작권

이 프로그램은 도구일 뿐이며, 무엇을 내려받을지는 쓰는 사람의 책임입니다.
저작권이 있는 영상을 권리자의 허락 없이 내려받아 배포하는 것은 저작권법에 어긋날 수 있습니다.
수업 목적의 이용이라도 「저작권법」 제25조가 정한 범위를 벗어나지 않는지 확인하고,
가능하면 저작권자가 이용을 허락한 영상(CC 라이선스 등)을 쓰시기 바랍니다.
